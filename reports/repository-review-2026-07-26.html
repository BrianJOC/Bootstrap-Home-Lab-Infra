Inferred goal

What this system is supposed to do

Guide a first-time homelab operator

  • Collect and strictly validate host, network, storage, secrets, recovery, maintenance, and paging choices.
  • Confirm and pin SSH identity, including an in-workflow changed-key recovery path.
  • Resume safely instead of demanding a clean reinstall.

Build a private platform

  • Install Technitium, wildcard TLS, Vault, PostgreSQL, Authentik, GitLab, MAAS, and an initial k3s cluster.
  • Use a single constrained Ubuntu host; TrueNAS is storage only.
  • Keep minimum protected runtime secret copies and allow manual Vault unseal.

Hand day-2 control to GitLab

  • Create the IaC project and reviewed pipelines.
  • Apply saved Terraform plans and migrate verified state to GitLab.
  • Coordinate backups, upgrades, certificates, reboots, health, and adoption without routine controller dependence.

Decision register

Settled—do not reopen as gaps

Accepted · secrets

Vault authoritative, pragmatic runtime copies

Preserve rerun material; manual 3-of-5 unseal is acceptable. A password manager may hold the init JSON. SPIFFE/SPIRE is deferred.

Accepted · trust

One-time fingerprint confirmation

Changed keys stop and notify the operator; the workflow can replace the pin only after explicit confirmation.

Accepted · network

Homelab first, UniFi rollout guide

MAAS DHCP is opt-in. Technitium can later serve the full home through network-by-network UniFi configuration.

Accepted · data

PostgreSQL before Authentik

Authentik starts directly on its final isolated database. The temporary database migration was eliminated.

Accepted · backup

Restic to TrueNAS, optional USB, trial mode

Defaults are presented and configurable. A first-time user can run without a backup destination, with an explicit degraded marker.

Accepted · lifecycle

Review-first upgrades with deadlines

Maintenance windows may auto-approve overdue application upgrades. OS security updates are automatic; reboots remain gated.

Accepted · telemetry

Bounded local observability

Telemetry runs on the target, never TrueNAS; 7-day maximum raw retention, tight CPU/memory budgets, optional free paging.

Accepted · recovery

Portable controller recovery

The separately encrypted SSH key and checksummed bundle support a read-only audit before explicit adoption.

Accepted · ownership

Ansible runtime, Terraform API objects

Go orchestrates. Ansible owns host/service lifecycle. Terraform owns durable API resources from first creation; clean bootstrap has no imports.
